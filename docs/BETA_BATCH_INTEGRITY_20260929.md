# AE Beta 第二轮批处理完整性修复与验收

2026-09-29，Windows x64；主验收宿主 After Effects Beta 27.0x58，兼容检查宿主 AE 2025 25.6.4x3。基于本地 `dee11bf` 继续修复，未把早前 PR #2 的 CI 当作本轮源码的验证结果。

## 实机复现与修复

修复前在 Beta 空白隔离工程中记录了下列 11 个负向用例。前 9 项见 `before.log`，MCP 封装见 `extended-before.log`，Unicode 对照见 `edge-cases.json`。这些是用例数，部分共享同一根因。

| 触发条件 | 修复前 | 修复后 |
| --- | --- | --- |
| 图层 index=true | 错选第 1 层并写入 | 拒绝布尔索引，工程不变 |
| 图层 index=1.9 | 截断为第 1 层并写入 | 拒绝小数索引，工程不变 |
| Shape 切线数量与顶点不匹配 | 静默接受并创建路径 | 创建前验证，失败不留下空组 |
| JSX dry-run 给透明度传二维数组 | 错报预检成功 | 拒绝不匹配的数值维度 |
| JSX dry-run 读取属性组 | 将属性组当成值属性 | 预检拒绝 |
| JSX 批次第二条路径不存在 | 第一条仍写入 12% 透明度 | fail_fast 预检失败时不开始任何写入 |
| JSX 对已有关键帧的属性做静态 set | 失败后的未执行项仍为 ok=true | 提前拒绝，未执行项明确失败 |
| 原生批次后续路径无效 | 先前未执行项仍为 ok=true | 返回 ok=false、executed=false |
| 工作流步骤返回结构化 ok=false | 后续步骤仍执行、整体报成功 | 传播失败，fail_fast 停止后续步骤 |
| MCP ae_call 包装结构化失败 | 外层仍返回 ok=true | 外层与底层失败一致 |
| 图层名含 U+2028 / U+2029 | JSX 字符串解析失败 | 安全转义，批处理与属性检查成功 |

另补充非有限数值、时间、文本布尔参数校验，以及原生错误回退的故障注入测试：只有明确缺少 PyShiftCore 对应导出时才使用 JSX 回退。超时或未知执行结果不得自动重放写操作。

## 仍存在的限制

- 本轮结束时 Computer Use 激活后缩成标题栏的根因尚未定位。随后第三轮已定位到标准工作区的坏还原矩形，并完成配置修复与跨重启验收；激活仍可能解除最大化。最新结论见 [窗口根因与修复记录](WINDOW_FOCUS_20260929.md)。此配置修复不计入本轮 11 个代码负向用例。
- 批处理预检减少可预知的部分修改，但不是数据库事务。执行阶段发生 AE/SDK 错误时，已经完成的写入不会自动回滚；executed 只表示尝试执行。
- JSX 写入支持标量、二维/三维、颜色、文本字符串、图层/蒙版索引；其他复杂值类型会明确拒绝，Shape 编辑走专用方法。
- 只在上述两个具体 AE 构建验证，未宣称覆盖其他 Beta 版本、第三方效果组合或所有真实大型工程。
- 最终切回 Beta 时一次启动无可见窗口且桥接未开放，经主人授权结束该进程后重启恢复。该启动异常未获得足够根因证据，单列记录，不归因于已修复的 AE2Claude 代码。
- 本轮为本地提交及安装验证；未推送远端，远端 CI 未覆盖本轮改动。

原始证据保存在本次对话工作区 `work/beta-round2/`；用户交付包包含前后日志、最终测试结果、安装核对、压力结果和渲染帧。
