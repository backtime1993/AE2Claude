# v4.4.0 发布验收清单

状态：Windows x64 / AE Beta 27.0x22 修复候选真机验收已完成；正式发布版本统一为 `4.4.0`。最终提交、稳定版复测、CI 和资产哈希随 Release 提供。

## 云端可复核的证据

CI 对每个候选提交运行以下检查，并保存带 SHA 名称的 Actions artifacts。
PR 工作流默认测试合并预览提交；Python 报告中的 `testedCommit` 是实际测试
提交，`headCommit` 是候选分支提交。请同时保留 CI run URL。

- Python 全套测试及明确的通过 / 失败 / 跳过列表；跳过真机测试不算真机通过。
- GCC 和 MSVC 编译运行两个独立 C++ 测试程序。它们不编译完整 AEX，也不覆盖真实 SDK 调用。
- PinClicker JavaScript 语法检查；它不证明 CEP 面板或真实点击可用。
- 从 sdist 构建 wheel，安装后在仓库外检查版本、CLI、全部登记脚本和新增 MCP 工具发现。
- Python / CLI / server / MCP / uv.lock / Codex 插件 / README 版本对齐。
- Python wheel、sdist、SHA256SUMS 与安装冒烟报告。它们不是完整原生插件安装包。

Artifacts 保留 30 天；发布前下载归档需要保留的日志。失败记录也可能产生
部分 artifact，必须同时核对对应 job 的 conclusion，不能仅凭附件存在就放行。

## 每次发布的最终检查

- [ ] 形成完整配套包：`build/Release/AE2Claude.aex`、匹配 server/bridge/protocol/CLI、
  MCP 包与配置、scripts、presets、安装工具、授权可分发的可选插件、许可证与源码入口。
  从包内实际位置运行安装，不依赖作者机器的目录或未打包文件。
- [ ] 完整包和 AEX 都有 SHA-256；发布包的构建提交与验收报告一致。
- [ ] 更新 [CHANGELOG](../CHANGELOG.md) 的未发布状态、当前验证统计、已知限制、
  升级与回退说明；不能将旧版测试统计标为本候选结果。
- [ ] 候选通过后再将各版本表面升为 4.4.0，更新锁文件并重跑发布检查。
- [ ] 根据发布授权合并、创建标签和 Release，并回读远端 SHA 与下载资产哈希。
