2026-09-29，Windows / After Effects Beta 27.0x58 / Computer Use 26.924.22138。

主人报告并提供截图后，已通过当前实例复现。先把 AE 恢复最大化，然后分别比较：

| 操作 | 观察结果（截图逻辑尺寸） |
| --- | --- |
| 只读 get_window_state | 1707×912 保持正常 |
| activate_window | 1707×912 保持正常 |
| 最大化窗口先最小化、再 activate_window | 恢复 1707×912 |

这里只能把触发路径定位到当前环境中的模拟组合键，尚未确定是输入注入、AE 本身还是第三方插件组合的底层问题。三个当前运行的个人 AutoHotkey 脚本中未发现该组合键或窗口缩放绑定。没有修改官方 Computer Use 包，也没有新增强制最大化的常驻程序。此项作为已验证规避记录，不计入 17 类 AE2Claude 源码修复。
