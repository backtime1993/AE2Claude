# Windows / AE 实机回归修复 — 2026-09-29

基于 PR #2 合并后的 `d1d1086f648db2364c5203a908e8d79b02ced6e5`，在 Windows x64 / After Effects Beta **27.0x58** 复现并修复下列 17 类问题。所有工程写入、强制退出和重启均使用临时测试工程，没有修改生产 AEP。

## 修复清单

| # | 实际问题 | 修复与验证 |
| --- | --- | --- |
| 1 | 轨道蒙版忽略指定来源，误用相邻图层 | 使用指定来源；非相邻来源和不存在来源均经回读验证 |
| 2 | 两种预合成 API 的 move_attrs=False 仍移动属性 | 传递真实布尔值；按名称、索引分别验证 |
| 3 | 批量预合成缺少目标仍处理其余图层 | 全部目标解析完毕才修改 |
| 4 | 调整图层顺序时移动自身或得到错误位置 | 基于原始目标位置向上/下移动 |
| 5 | 指定时间读取属性时忽略表达式 | 默认采样表达式后的值，新增显式 pre_expression 参数 |
| 6 | 定格保留内部时间重映射关键帧，仍然运动 | 替换旧关键帧为单个 HOLD 值；三个时刻渲染逐像素一致 |
| 7 | Unicode 行分隔符导致 JSX 语法错误，CR 被删除 | ES3 安全字符串转义，保留原内容 |
| 8 | 无效蒙版切线创建残留蒙版 | 写入前校验几何；配置失败仅删除刚创建的蒙版 |
| 9 | 创建控制空对象时，缺失子图层导致部分绑定 | 全量解析子图层后才创建及绑定 |

| 15 | 倒放首帧越过素材末端，旧重映射关键帧仍生效 | 使用最后实际源帧，替换旧键；首末帧与源帧逐像素比对 |
| 16 | 冷启动时全局 JSON 尚未被其他扩展初始化，正常查询失败 | 随包提供 JSON2 局部回退，不依赖第三方扩展启动顺序 |
| 17 | AE 模态窗口打开时执行 JSX 触发第二个阻塞错误窗口 | Windows 原生调用前检查主窗口可用性，返回 host_modal_dialog / not_started / retrySafe |

## 复测入口与限制

在空白、未保存且无修改的测试实例中运行（live 测试会创建并清理临时工程）：

```powershell
$env:AE2CLAUDE_LIVE_TEST='1'
uv run python -m unittest discover -s tests -v
uv run python tools/stress_test.py --requests 200 --workers 8 --write-cycles 12 --layers-per-cycle 30 --agent-operations 200
```

本节原始验收范围为 Beta 27.0x58 / Windows；同日后续完成了 [AE 2025 25.6.4x3 验收](AE2025_ACCEPTANCE_20260929.md)。这不代表其他版本、macOS 或所有第三方插件组合均已验证。主窗口模态检查仅适用于 Windows；AE 不投递 idle 回调时，仍可能等待或超时。超时和连接中断仍代表结果未知，不能据此重放写入。

`reverse_layer` 明确定义为把整个源素材倒放到图层可见时间段，会替换原重映射曲线，不是对既有复杂变速曲线求逆；存在启用的时间重映射表达式时拒绝。`freeze_frame` 时间以源素材秒数为准。蒙版动画顶点数量变化时，新切线置零。

原生 matchName 查找每组最多枚举 10000 个子属性；重名必须用零基 SDK 索引消歧。SDK 索引不保证等同 JSX 属性索引（效果可能有隐式输入参数）。预检和 undo group 不等于对所有运行中 SDK 异常提供事务回滚。

启动设置是一次性持久配置，版本升级或首选项重置后需要重验；它保留自动保存与未保存工程恢复行为。没有发布新版本或验证新的远端 CI；上述结果均为本机修复分支验收。
