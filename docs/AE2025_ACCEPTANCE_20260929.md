## Limits and observations

The verified release host is specifically **25.6.4x3 on this Windows machine**, not every AE 2025 patch or third-party plugin combination. Beta and release share ports 8089/8891 and should run one at a time for automation. Installed copies in two host directories do not constitute independently maintained versions.

One early run following normal startup received transient `host_modal_dialog` rejections. No persistent dialog was visible when inspected; later read probes and the complete suite passed. The exact trigger was not established. HTTP health alone is not proof that AE can execute work, and unknown write outcomes must never be replayed. The final full suite also passed after the abnormal-restart test.

An optional verification script repeatedly evaluated `app.effects` while enumerating third-party effects and exceeded its 60-second client deadline. It was not replayed, the operation subsequently completed, host readiness was rechecked, and the final full suite passed. This was an inefficient one-off audit expression, not a change to the runtime. No production project was modified.

Startup settings depend on existing version-specific preference keys and must be rechecked after upgrades or preference resets. No new release or remote CI run is claimed by this local acceptance.
